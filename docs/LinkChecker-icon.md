# 網頁連結檢查器圖示

**生成方式：內建 image_gen 工具。**

藍色鏈結代表網頁資源網址，綠色勾選代表驗證成功，採用腳本既有的
`#3B82F6` 與 `#22C55E` 狀態顏色。圖示不含文字，以鏈結與勾選輪廓表達功能。

檔案：[LinkChecker.png](../images/LinkChecker.png)。尺寸為 1254 × 1254 像素，
格式為 RGBA PNG，保留生成結果的透明背景。腳本以 `@icon` 引用 GitHub
儲存庫中的原始圖片網址；圖片推送至遠端後，該網址才會提供新圖示。

```text
Use case: logo-brand
Asset type: production PNG icon for the LinkChecker Tampermonkey userscript, square canvas, intended to remain legible at 16, 32, and 64 pixels.
Primary request: design one original icon that immediately communicates checking and validating webpage resource links, including image links.
Scene/backdrop: genuinely transparent background with an alpha channel; no background tile.
Subject: two bold interlocking chain links forming a compact diagonal silhouette, combined with one simple green validation check badge. Keep both chain links recognizable and the check unmistakable.
Style/medium: clean flat graphic with smooth geometric curves, thick shapes, crisp edges, and generous open spaces. A restrained functional browser-tool icon.
Composition/framing: one centered icon, visually balanced, filling approximately 80 percent of a square canvas with safe padding on every edge. Badge integrated with the chain without obscuring the interlocking join.
Color palette: use the existing userscript status colors: blue #3B82F6 for the chain, green #22C55E for the validation badge, white for its check.
Constraints: exactly one icon; strong silhouette and high contrast at small sizes. No text, letters, numbers, mockups, presentation sheets, alternate variants, decorative image thumbnails, watermarks, gradients, drop shadows, 3D effects, or checkerboard pattern. Transparent pixels must be actual transparency.
```
